# User testing: founder report (task C9)

**Goal:** show the founder report (C6) to 3–5 founders at Junction, learn whether the Pitch and
Skip lists change who they'd pitch, and get **one quote** for the pitch.
**Time:** about 7 minutes per founder. One person talks, one takes notes in this file.

## Before you start

- [ ] App running. Before C8 (until B's real API lands) it runs on the mock, from `frontend/`:
      `npm run mock` and `API_URL=http://localhost:8001 npm run dev`, then <http://localhost:3000>.
      After C8: point `API_URL` at B's server or use the deployed URL.
- [ ] Laptop on the home page, "I'm raising" selected, window wide, nothing else open.
- [ ] **On the mock only Kelluu, Sensofusion and Stendr have reports.** Ask the founder to play
      Kelluu's founder (Finnish defence startup, raising after a €15M Series A). After C8, try their
      own company first, then fall back to Kelluu if Cala doesn't know it.
- [ ] Ask before quoting: *"Can we quote you in our demo, with your first name and company?"*

## Script

**1. Context (30 s).** "We're building a tool for founders raising at Slush. We're testing the
tool, not you. There are no wrong answers; please think out loud."

**2. Warm-up (1 min).**

- "How did you build your last investor list?"
- "Have you ever pitched an investor who turned out to back a competitor?"

**3. Task (3 min). Don't help unless they're stuck for 30 s.**

- "Find who you should pitch for Kelluu." *(Watch: do they find the search, pick the right
  entity when there are several matches?)*
- "Who's the best fit, and why do you believe that?" *(Watch: do they read the reasons, open a
  source badge?)*
- "Is there anyone you should *not* pitch?" *(Watch: do they find the Skip list, understand the
  conflict line?)*
- "One of these competitors looks wrong to you. Remove it." *(Watch: do they find the ×, and
  re-rank?)*
- Optional: "Now imagine you're that investor. What would they see?" *(The Flip link on a Skip
  card.)*

**4. Questions (2 min).**

- "Would this change who you pitch? Who would you drop or add?"
- "Which part do you trust least? What would make you trust it?"
- "What's missing that you'd need before Slush?"
- "If this disappeared tomorrow, how would you feel?" *(Very / somewhat / not disappointed.)*

**5. Close (30 s).** Thank them; ask for the quote permission if they said something good.

## What to note

Write what they **do and say**, not what you think. Quotes word for word, in quotation marks.
Mark each observation: ✅ worked · ⚠️ hesitated / confused · ❌ failed or wrong conclusion.
